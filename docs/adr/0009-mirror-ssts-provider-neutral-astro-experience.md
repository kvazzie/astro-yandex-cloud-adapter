# Mirror SST's provider-neutral Astro experience

The future Yandex SST component is a drop-in replacement for `sst.aws.Astro` at the level of provider-neutral author experience: project path, build command, links, environment, development behavior, outputs, and customization. It provisions Yandex Target resources by default, keeps state-backend selection user-owned, and exposes Yandex-specific capabilities explicitly rather than pretending AWS-only properties have direct equivalents.
