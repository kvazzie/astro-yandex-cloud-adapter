Keep generated API Gateway templates buildable for a prerendered
homepage beside an on-demand catch-all and for a static parent
beside a required parameter route. Select identical-path winners
before validating priority conflicts between different paths.
Compare priorities only at URLs Astro can match with both routes,
encode literal braces in recursive 404 scopes, and publish
prerendered pages at their canonical URL spelling. Image and
server-island evidence ignores HTML comments, honors the document
`<base>` element and counts only requests to the application.
Read emitted HTML with the standards-compliant parse5 parser, so
template contents, character references and custom elements are
read as a browser reads them. Scan each document at the URLs the
Gateway serves it at, let a stored route keep a path that a
redirect-only alias shares, and project very large prerendered
routes without exceeding the engine's argument limit. Index plan
paths and skip fixed-path pairs, so a template with many
prerendered paths reaches the size guard quickly. A `<base>` URL
is not an image request, a `data:` or `javascript:` base falls
back to the document URL, and a base ending in `/404` is not a
404 scope.
